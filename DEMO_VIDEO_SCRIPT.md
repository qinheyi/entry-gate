# Entry Gate — demo video script (&lt;3 minutes)

**Target length:** 90–150 seconds (hard max 180s)  
**Format:** Screen recording, English voiceover or on-screen captions  
**Upload:** YouTube or Vimeo, **public**  
**Who uploads:** Qin HEYI (manual)

## Shot list

| Time | Visual | Say / caption |
|---|---|---|
| 0:00–0:10 | Open https://entry-gate.vercel.app — show “Alexa+ simulation · ready” header | “Entry Gate is a simulated Alexa+ submission steward. It verifies your hackathon demo, repo, and video before you hit Submit.” |
| 0:10–0:25 | Click **Try Encore** — fields fill; audit runs; show pulse “listening…” | “I’ll audit Encore, a prior hackathon project, with one click.” |
| 0:25–0:50 | Show verdict badge **almost · 9x/100**, checklist, ranked fix “Record a &lt;3 min demo…” | “Deterministic tools probe the live demo and GitHub. No video yet — verdict is almost, not go.” |
| 0:50–1:05 | Expand **Tool trace**; briefly show fetch_page / check_repo / score_checklist | “Every claim is backed by a tool trace — don’t trust the agent without verification.” |
| 1:05–1:20 | Click **Speak** (optional); then **What should I fix first?** follow-up | “Spoken summary and multi-turn follow-ups — Alexa+-style session, not a one-shot FAQ.” |
| 1:20–1:45 | Click **Audit Entry Gate**; show self-audit on entry-gate.vercel.app + qinheyi/entry-gate | “It can audit itself the same way judges will open the live demo.” |
| 1:45–2:10 | Optional: paste a short public YouTube URL into Video and re-audit | “Add a public YouTube or Vimeo link and re-run — closer to go.” |
| 2:10–2:25 | Cut to GitHub https://github.com/qinheyi/entry-gate — LICENSE MIT, README | “Public MIT repo with source for the simulation — as required for the Alexa+ simulated path.” |
| 2:25–2:40 | End card: demo URL + repo URL on screen | “Entry Gate — build, verify, then submit. Demo: entry-gate.vercel.app” |

## Recording tips

- 1280×720 or 1920×1080; dark UI reads well — avoid busy desktop wallpaper.  
- No copyrighted music.  
- Lead with the Encore **almost** moment — judges may stop watching early.  
- If voiceover is hard, use large captions with the same lines.  
- After upload, set visibility to **Public**, copy the URL into Devpost + Entry Gate’s Video field, and re-audit.

## After upload checklist

1. Paste video URL into Devpost draft  
2. Paste into Entry Gate Video field → **Re-audit**  
3. Screenshot the improved verdict for the gallery
